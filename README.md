The GitHub Actions artifact contains `VeilChapter1122-0.2.4-alpha-internal.jar`. Install only the JAR in your test Forge 1.12.2 profile’s `mods` folder, not the source ZIP.

Implemented foundations: progressive story days, dark observer, blindness proximity, “psst” sound, floating-block anomalies, some day-six events, and an experimental giant tree dimension. Risky options (world destruction, entity stasis, seamless teleportation and tree scene) are disabled by default.

Dynamic Lights remains external and is not included.
